# Proceso Unificado RUP

Página concentradora de las disciplinas, fases y artefactos del sistema de **Gestión OTRI**, siguiendo el marco metodológico de **Rational Unified Process (RUP)** y los estándares de **Ingeniería del Software (IdSw)**.

## Información del proceso
* **Proyecto:** 26-27-IdSw1-SDR · Gestión OTRI
* **Asignatura:** Ingeniería del Software I · UNEATLANTICO
* **Metodología:** RUP iterativo e incremental con trazabilidad bidireccional
